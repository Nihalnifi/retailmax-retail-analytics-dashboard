# RetailMax Retail Analytics Dashboard

## Project Overview

This project is an interactive retail analytics dashboard developed using Power BI to analyze sales performance, customer activity, transactions, cancellations, and overall business performance.

The project involved combining data from multiple sources, cleaning and transforming the data, creating a data model, and building interactive dashboards using Power BI.

## Tools Used

- Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## Data Preparation

The project used 4 different data sources.

Power Query was used to:

- Combine data from multiple sources
- Clean and transform the data
- Handle data inconsistencies
- Prepare the data for analysis

A star-schema data model was created to establish relationships between the tables and support efficient analysis.

## Key KPIs

The dashboard tracks important business metrics including:

- Revenue
- Net Units
- Cancellations
- Customers
- Transactions
- Week-over-Week (WoW) Growth

DAX measures were created to calculate and track these KPIs.

## Dashboard Features

The project includes 5 interactive dashboards with:

- KPI cards
- Charts and visualizations
- Slicers
- Drill-through functionality
- Interactive filtering
- Sales performance analysis

These dashboards allow users to explore business performance from different perspectives.

## Analysis Performed

The dashboard provides insights into:

- Overall sales performance
- Revenue trends
- Customer activity
- Transaction performance
- Cancellation trends
- Unit sales
- Week-over-Week growth
- Retail business performance


## Objective

The main objective of this project is to build an interactive Power BI reporting solution that makes retail data easier to analyze and helps users understand key business performance metrics.
